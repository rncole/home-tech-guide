\chapter*{About this guide}
This guide explains the technology used across a household and its personal web projects. Start with the smallest useful setup, then add integrations as each layer becomes dependable.

The examples use fictional domains and omit credentials, private endpoints and household identifiers. Confirmed use, behavior present in reviewed configuration and illustrative or unfinished work are distinguished in the chapters. Configuration in GitHub is not a live deployment audit.

This PDF is generated from the repository Markdown. Diagrams are rendered from Mermaid and included as vector figures. Chapter links stay inside the PDF; official documentation links remain clickable.

\vspace{5mm}
{\sffamily\bfseries Reading order}\par
Getting started; online services; home infrastructure; smart home and daily use; building applications; keeping it running.
